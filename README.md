# Broken Access Control — ЛР №5

Презентація-сайт до лабораторної роботи №5 з курсу «Безпека веб-додатків».
Статичний сайт без збірки: `index.html` + `style.css` + `app.js` + `data.js` + `assets/`.

## Керування

| Дія | Клавіші |
| --- | --- |
| Наступний крок / слайд | `→` `↓` `Space` `PageDown`, колесо миші, свайп вліво |
| Попередній | `←` `↑` `PageUp`, свайп вправо |
| Перший / останній слайд | `Home` / `End` |
| На весь екран | `F` |
| Збільшити скріншот | клік по скріншоту, `Esc` — закрити |

Адреса запам'ятовує позицію: `#9.4` — слайд 9, крок 4.

## Як заповнити текст

Увесь текст лежить у `data.js`:

- `labs[n].desc` — опис вразливості;
- `labs[n].steps` — кроки: `{ t: 'текст', f: [номери рисунків] }`;
- `captions` — підписи рисунків (`12: 'Рисунок 12 – ...'`).

Скріншоти: `assets/fig-01.png` … `fig-55.png`, нумерація як у звіті.

## Локальний перегляд

```bash
python -m http.server 8000
```

і відкрити http://localhost:8000

## GitHub Pages

1. Створити репозиторій і завантажити вміст цієї папки в гілку `main`.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`.
3. Через хвилину сайт буде на `https://<логін>.github.io/<репозиторій>/`.
